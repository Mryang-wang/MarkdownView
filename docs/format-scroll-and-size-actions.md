# 格式操作与阅读位置修复

2026-10-15，基于 1.3.8 的后续源码修改。本轮未打包，已有安装包不包含这些后续修复。

## 字号操作

- 顶部字号主按钮显示并直接应用记住的字号；右侧小箭头打开常用字号与自定义输入。
- 悬浮工具条显示同一个字号，点击打开字号面板，可选择常用字号或输入自定义数值。
- 选中文字后选择字号，会应用并记住该值。没有选中文字时，选择字号只更新记住的值；点击主按钮不插入占位文字，也不修改正文。
- 支持 6–96 pt、0.5 pt 步长；取消或 Escape 不提交输入中的数值。恢复正文字号只重置所选内容，保留上次选择的快捷字号。
- 字号由当前文档的编辑器记住，与原有高亮颜色一致；不作为所有文档的全局正文设置。

## 悬浮下拉选项

悬浮工具条的高亮、下划线和文字颜色拆为两个独立按钮：点击图标直接应用记住的颜色或线型，点击右侧小箭头才打开选项。两部分保持相邻，窄窗口换行时不会拆开；均可通过键盘聚焦。字体与字号仍点击打开面板。面板紧邻点击的按钮，随窗口边界调整位置；加粗、斜体继续一键操作，批注和翻译继续打开对应侧栏。

打开面板本身不修改正文；选择后应用到原选区。再次点击同一箭头或按 Escape 可关闭，取消保留原选区。字号、文字颜色、高亮颜色和下划线样式与顶部工具栏共用状态。顶部文字颜色同样拆分为直接应用图标和选色箭头；取消输入中的颜色不改变已确认的颜色，重新打开面板显示已确认值，无选区点击颜色图标不插入内容。沿用已有面板，不增加第三方依赖。

## 同类跳转修复

格式面板提交或取消时，恢复选区的公共函数原先先调用普通聚焦。正文是可滚动的编辑元素，浏览器会先将它滚到顶部，再恢复所选文字，因此即使选区正确，阅读位置仍已丢失。

改为先验证／找回选区，再使用不触发滚动的聚焦。修复覆盖字号、字体、文字颜色和段落行距的应用、取消，以及需要重建字体显示节点时的选区恢复。不增加延时回滚、持续轮询或额外全文扫描。

另外修复高亮面板打开期间正文刷新后，选择颜色未应用到原选区的问题。字号和高亮均先根据文本书签找回选区，再判断是否可以应用，避免把刷新后失效的旧选区误认为“没有选中文字”。
