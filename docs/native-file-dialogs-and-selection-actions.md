# 悬浮操作、图片路径与原生文件窗口

本轮基于 1.3.7 源码修改，纳入 1.3.8 源码；安装包和构建产物仅在本地维护，不上传到公开仓库。

## 使用方式

- 选中文字后的悬浮工具条新增“添加批注…”与“翻译选中内容…”。批注在右侧打开输入框；翻译沿用已有模型配置与右侧翻译栏。支持即时渲染、所见即所得、源代码模式，点击按钮时保留准确选区。
- 右击本地图片，选择“打开图片所在文件夹”，由系统打开对应目录。支持 Markdown 相对路径、绝对文件地址，以及中文、空格和特殊字符。链接中的图片按图片自身的地址定位。网络图片、内嵌图片没有本地目录，菜单项禁用；目录失效或系统无法打开时显示提示。
- 打开文档、打开项目文件夹、导入图片、另存为、导出 Word / PDF、另存译文、选择模板、移动文件与打包分享等文件选择入口，统一恢复系统原生窗口。左侧导航和固定路径由 Windows 管理，软件不再自定义这些区域。
- 软件内的设置、消息、未保存确认和导出完成窗口继续跟随现有界面风格。原生文件窗口的外观由系统决定，可能与软件的深浅主题不同。

## 实现与开销

悬浮条仍只创建一次；两个新增按钮复用已有批注与翻译流程，不增加常驻轮询或全文扫描，也不新增运行依赖。工具条的显示动画、高亮共享颜色、窄窗口换行保持原有逻辑。

取消全局禁用原生对话框的设置，将文件选择窗口排除在应用主题处理之外；应用消息框单独保留自定义样式。保存窗口仍在确认文件前补齐默认 `.md` 后缀，以便覆盖确认检查正确的目标文件。

## 本地验证

环境：Windows、Python 3.12、Qt WebEngine 6.11.1。以下测试脚本、截图和运行日志仅在本地保留，不加入应用资源或安装包。

| 检查 | 结果 |
| --- | --- |
| `test_selection_toolbar.py` | 三种模式的悬浮批注创建、保存、删除及准确选区翻译通过；格式操作、撤销、深浅主题、英文、窄窗口和减少动画回归通过；未发送远程模型请求 |
| `test_image_context.py` | 三种模式实际右键菜单通过；带链接的图片、中文与特殊字符路径、内嵌图片禁用、远程地址防护、目录丢失和打开失败提示通过；测试拦截系统打开调用以核对目标目录 |
| `test_native_file_dialogs.py` | 识别到实际 Windows Shell 文件窗口及系统导航树；真实图片导入、保存后缀、覆盖接受／拒绝、取消通过；打开文档、项目目录、Word / PDF 导出选择窗口均使用系统窗口；应用消息深浅样式通过 |
| `test_save_suffix.py` | 通过系统原生窗口验证新建文档、另存为、显式后缀、所有文件类型、连续保存、覆盖／取消及保存后重新打开 |
| `test_export_dialog.py` | 实际 Word / PDF 导出、完成提示、英文和深色界面通过 |
| `test_unsaved_dialog.py` | 未保存文档的保存、放弃、取消、Escape、退出保护及窄窗口通过 |

含 300 个段落、600 个公式的文档中，本轮悬浮条显示采样 108 帧：帧间隔第 95 百分位 16.8 ms，最大 33.3 ms；无超过 50 ms 的浏览器长任务，无正文节点变更，动画结束后无活动动画。这是本机单次显示路径的检查，不代表所有机器和所有操作都能保持固定帧率。
