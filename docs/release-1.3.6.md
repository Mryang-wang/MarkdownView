# 1.3.6 安装包验证

2026-10-12，Windows、Python 3.12、PySide6 / Qt WebEngine 6.11.1。基于当前工作区源码构建，包含尚未提交的最新修改。

## 包含的改动

- 普通正文输入、批注定位与字数统计减少重复计算；侧栏动画通过裁切编辑器减少连续重排，工具栏换行调整为位移过渡。实测及限制见 [掉帧优化记录](frame-pacing-and-comments.md)。
- 批注按对应原文位置排列，双击正文即可编辑，保留键盘操作与保存／取消。
- 最大化窗口拖动时先还原，再交给系统继续移动与分屏；修正还原图标，顶部菜单增加少量留白。源码检查见 [窗口修复记录](window-caption-fixes.md)。
