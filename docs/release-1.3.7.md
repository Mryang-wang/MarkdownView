## 本版改动

- 选中文字后就近显示字体、字号、加粗、斜体、下划线、文字颜色与高亮工具条。
- 顶部高亮主按钮直接应用颜色，小箭头选色；悬浮高亮直接应用同一个颜色，不打开颜色面板。
- 支持轻量进场动画、深浅主题、窄窗口与减少动画设置。源码功能与性能检查见 [选区悬浮工具条验证记录](selection-toolbar.md)。
- 包含 1.3.6 的流畅度、批注排序与双击编辑、最大化拖动和窗口图标修复。
