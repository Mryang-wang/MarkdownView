# 选区统计、批注与界面语言

## 文字统计

选中正文后，左下角显示“选中 X / 全文 Y”；取消选区后显示全文字数。中文按字符计数，英文和数字按连续单词计数。Markdown 格式标记、HTML 格式标签和批注数据不计入正文文字。

点击左下角可查看选区的详细统计；没有选区时显示全文统计。即时渲染、所见即所得和源代码模式均支持选区统计。

## 批注

- 选中正文，右键选择“添加批注…”，或使用“编辑 → 添加批注…”及 `Ctrl + Alt + M`，输入内容并点击“添加”。右键菜单仅在选中正文时启用此项。
- 点击批注卡片中的原文片段，可以定位选中文字。
- 点击卡片右上角的 ×，或“编辑 → 删除当前批注”，删除批注。
- “视图 → 显示批注 / 隐藏批注”及工具栏的气泡按钮控制面板和正文标记。隐藏不会删除批注，也不会清除尚未提交的输入。

顶部只保留“文件、编辑、视图、设置、帮助”五个菜单。

保存 Markdown 文件时，批注以带版本标记的 HTML 注释写入文件尾部。本软件加载时会提取批注，不把数据放入编辑正文。复制文件即可携带批注；自动保存和草稿恢复复用同一份数据。其他 Markdown 阅读器通常忽略 HTML 注释，其源代码视图可能显示这些数据。

原文前方的文字变化会更新批注位置。同一段文字在多个位置出现时，使用上下文区分位置；原文删除后仍保留批注，并标记“原文已修改或删除”，避免自动挂到另一处相同文字。DOCX / PDF 导出保留正文，不导出本软件的批注面板或数据。

## 语言

“设置 → 语言”提供简体中文和 English。切换即时作用于菜单、侧栏、编辑工具、统计、批注及提示；已打开的其他软件窗口同步更新，重启后保留选择。正文和批注内容不翻译，文档的撤销历史保留。

页面右键菜单随所选语言显示。在简体中文下，撤销、重做、剪切、复制、粘贴、全选及链接、图片操作显示中文。Windows 自身的原生系统界面使用系统语言。

## 导出完成提示

DOCX 和 PDF 导出完成后显示统一的圆角提示窗口，包含成功标识、文件名、格式及保存目录。长名称和路径可悬停查看完整内容；存在转换提示时，可点击“查看导出提示”展开。窗口支持深浅主题和中英文，按 Enter 完成，按 Esc 或右上角 × 关闭。

## 验证

`test_mouse_navigation.py` 通过实际 Qt 鼠标事件验证三种编辑模式的滑块拖动、轨道翻页及箭头光标，以及最大化、全屏、隐藏侧栏、深色主题、批注面板和宽代码块的滚动操作。滚动条加宽到 12 像素，正文保持文字光标并支持拖选。测试还验证侧栏滚动不会误选或拖出文档，以及退出全屏后恢复最大化状态和原有窗口尺寸。

`test_window_resize.py` 验证普通窗口的四条边和四个角：独立的 6 像素边缘区域显示对应方向的缩放光标，四角沿边缘延伸至 16 像素，鼠标按住后可移出窗口继续拖动，松开即停止。角部使用 L 形区域，不覆盖正文和滚动条；最大化和全屏时隐藏这些区域，还原后重新启用。

窗口缩放现在优先交由 Windows 原生机制处理，避免手动计时刷新与窗口合成不同步；仅在系统不支持时回退到手动缩放。`test_native_window_resize.py` 验证真实 Windows 缩放循环的八个方向和取消操作；原有 `test_window_resize.py` 则专门验证兼容回退路径。两种测试均不操作全局鼠标。

`test_review_language.py` 使用真实 Qt / WebEngine 界面验证选区和全文计数、统计弹层、添加批注快捷键、编辑菜单中的添加与删除批注、视图菜单中的显示与隐藏批注、重复文字定位、原文改动、三种编辑模式、保存重开、草稿备份、安全显示批注文本、中英文切换、原生右键菜单及切换语言后撤销历史。右键菜单中的“添加批注”已通过真实菜单点击验证。

`test_export_dialog.py` 实际导出 DOCX 和 PDF，验证成功弹窗、深浅主题、中英文、长文件名、转换提示展开收起和键盘关闭；导出失败仍走错误提示。

现有格式与导出、查找替换与恢复、编辑器缓存、菜单提示和未保存文档保护测试均已通过。这些功能已于 2026-10-03 纳入 1.1.3 安装包。
