# 1.3.4 新建文档保存后缀修复

2026-10-09，在 Windows、Python 3.12、PySide6 6.11.1 的真实保存对话框中复现：输入“新建笔记”后，旧版写出的文件名称为“新建笔记”，没有 `.md` 后缀。

保存与“另存为”现改为显式配置保存对话框的默认扩展名 `md`。后缀在对话框内确定，覆盖确认也检查最终的 `.md` 路径，避免在确认结束后才补后缀而绕过同名文件保护。参考 [Qt QFileDialog 默认后缀与保存确认](https://doc.qt.io/qtforpython-6.11/PySide6/QtWidgets/QFileDialog.html)。

3 个相关本地源码回归脚本通过，覆盖：

- 未命名文档首次保存时自动补后缀；再次保存使用原文件，不生成 `.md.md`。
- “另存为”、中文及带空格路径、选择“所有文件”后省略后缀。
- 显式 `.md`、`.MD`、`.markdown`、`.txt` 后缀保持不变。
- 取消保存保持原路径和草稿；最终 `.md` 文件已经存在时，分别拒绝／同意覆盖。
- 保存后关闭窗口，重新打开文件，正文可读取、渲染。
- 未保存文档关闭流程、图片首次保存及另存目录迁移、草稿和会话恢复。

此前已经保存成无后缀的文档，可以在资源管理器中将文件名改为“文件名.md”后重新打开；更新不会自动改名用户已有的文件。

测试脚本及日志仅在本地维护，不上传仓库或包含在安装包内。
