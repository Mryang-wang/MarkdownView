# 选区悬浮工具条

日期：2026-10-14。此功能在 1.3.6 之后加入，现已纳入 1.3.7 安装包，打包检查见 [1.3.7 安装包验证](release-1.3.7.md)。

## 使用方式

- 在即时渲染、所见即所得或源代码模式中选中文字，松开鼠标后显示悬浮工具条；也支持用 Shift 配合方向键、Home / End 选字。
- 提供字体、字号、加粗、斜体、下划线、文字颜色与高亮。字体、字号和文字颜色面板在悬浮按钮附近打开，沿用顶部工具栏的格式处理、保存和导出逻辑。
- 顶部高亮分为主按钮和小箭头：主按钮直接应用当前颜色，小箭头打开预设与自定义颜色。没有选中文字时，选择颜色只更新当前颜色，不插入内容。
- 悬浮高亮只应用同一个颜色，不打开颜色面板；下划线也沿用顶部选定的线型。
- 拖选和输入法组字时不显示；滚动、继续输入、按 Escape、点击外部或离开窗口后收起。只读状态不显示。
- 工具条限制在当前编辑栏内，窄窗口自动换行；支持深浅主题、中英文界面与系统减少动画设置。

## 显示开销

悬浮工具条只创建一次，等待选区稳定 60 ms 后在动画帧中定位。出现时只读取选区的两个端点，不扫描全文，也不测量整个跨段选区。定位与显示不修改正文节点。

使用 140 ms 的透明度与 4 px 位移动画，动画期间不修改宽、高或布局位置；没有背景模糊、持续轮询或常驻动画。沿用项目原有资源，不引入运行依赖。

在本机 Windows / Python 3.12 / Qt WebEngine 6.11.1 环境中，用 300 个段落、600 个公式的文档记录一次选区工具条出现前后的约 1.8 秒：

| 项目 | 实测 |
| --- | --- |
| 有效帧间隔样本 | 107 |
| 帧间隔第 95 百分位 | 16.7 ms |
| 最大帧间隔 | 33.3 ms |
| 超过 50 ms 的浏览器长任务 | 0 |
| 正文节点变更 | 0 |
| 动画结束后的活动动画 | 0 |

以上是单机、单次显示路径的检查，不代表所有机器或所有格式操作都能保持固定帧率。

另通过 Chromium 性能跟踪检查进场动画：真实选区出现时，顶部编辑工具状态更新带来一次约 0.27 ms 的布局；待这些状态更新完成后单独记录同一段进场动画，初始帧之后没有 Layout / Paint 事件。已分别截取深浅主题下 0 / 70 / 140 ms 的画面，检查文字未被拉伸、控件未被裁切。

## 验证范围

本地 `test_selection_toolbar.py` 已通过以下检查：

- 三种编辑模式中的加粗、斜体、下划线、高亮及撤销。
- 字体、字号和文字颜色操作保留目标选区；顶部与悬浮工具条的颜色一致。
- 真实鼠标正向、反向拖选与 Shift 键盘选字；按住鼠标拖选期间不出现工具条。
- 顶部主按钮直接高亮、小箭头打开选色、悬浮高亮不打开面板，以及无选区选色不插入文字。
- 弹出面板就近定位、Escape 取消、只读、滚动、输入、输入法组字及空选区。
- 深浅主题、英文界面、减少动画、窄窗口边界、保存及 JavaScript 错误检查。

同时通过本地既有回归 `test_inline_formats.py`、`test_font_formats.py`、`test_text_styles.py`、`test_ui_motion.py`，覆盖保存后重新打开、混合格式、跨段与表格内文字、撤销重做、Word 原生格式、PDF 渲染，以及侧栏收起、工具栏换行、快速反向切换和减少动画设置。顶部新增选色箭头后，动效测试的最大窗口宽度从 1380 调整到 1440，以继续覆盖从两行变成一行的边界。

`test_selection_animation.py` 保存实际选区出现和单独进场动画的两份性能跟踪及定格截图；以上共六个相关本地脚本通过。

测试脚本、截图和性能原始记录仅保留在本地，不加入应用资源或安装包。
