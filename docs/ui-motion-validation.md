# 轻量交互动效

源码验证日期：2026-10-11；1.3.5 安装包验证日期：2026-10-12。Windows、Python 3.12、PySide6 / Qt WebEngine 6.11.1。

## 交互变化

- 左侧栏约 250 ms 展开／收起，正文区域同步伸缩。侧栏内部保持固定宽度并平移，文字和按钮不会被压窄。连续反向操作从当前位置继续，隐藏窗口或进入全屏时清理未完成的动画。
- 工具栏仍按单个按钮排列。宽度变化、按钮换行时，用约 250 ms 的位置过渡衔接；行数改变时平滑调整工具栏高度。字体、语言等导致按钮尺寸变化时同样更新布局。
- 查找、字体、字号、文字颜色、表格、高亮、下划线及行距面板使用约 200 ms 的轻微位移和淡入；右侧批注与选区翻译面板约 250 ms 滑入。关闭立即响应，保留原来的键盘操作和焦点逻辑。
- 读取 Windows 的界面动画偏好；系统关闭动画时，侧栏和网页面板同步停用过渡。网页层也遵循 `prefers-reduced-motion: reduce`。

方案参考 [Motion Ref](https://github.com/joepUI/motion-ref-skill) 的侧栏、布局和浮层动效。使用现有 Qt、CSS 与 Web Animations API，不添加动画运行库。

## 资源与实现

- 新的布局观察器只关注编辑器尺寸和工具栏，不扫描或改写正文。工具栏高度变化不再触发自身的布局观察循环。
- 同类动画替换尚未结束的动画，并在结束后释放动画记录及临时高度；隐藏的文档取消过渡。没有持续的动画轮询。
- 收放侧栏和切换主题时不再重复发送语言字典或遍历界面翻译标签；只有首次加载和实际更换界面语言才执行。

使用 240 段正文、240 个小标题和 240 个公式测试。一次收起过程及随后稳定阶段的浏览器帧间隔中位数约 16.7 ms、P95 约 33.3 ms，测量区间内没有超过 50 ms 的浏览器长任务。原文滚动位置在该次收起前后均为 3520.5 px，正文和脏状态未变化。数据来自本机单次实测，不代表所有设备、文档的固定帧率，也不表示减少了 Qt WebEngine 的基础内存。
