# 字体、字号、字色与功能检查（2026-10-07）

本轮修改已完成，本次 GitHub 更新仅发布源码、文档及测试，未重新打包或上传 EXE。

## 新增与完善

- 顶部“字体”“字号”“文字颜色”分别作用于选中文字，支持句子、段落和表格单元格。
- 字号范围 6–96 磅，步进 0.5 磅，提供常用中文字号和恢复正文字号。
- 字色提供八种预设、系统选色器、十六进制输入和随主题变化的自动颜色。
- 三种编辑模式支持保存重开、撤销／重做；Word 保留可编辑格式，PDF 保留排版与字色。
- 控件跟随深浅主题、中英文界面，在 480 × 360 最小窗口下检查可达性和溢出。

## 已修复的问题

- 简写图片引用 `![asset]` 在另存、图片管理及 ZIP 分享时可能漏图。
- `.mdown/.mkd/.mkdn` 文件跨目录移动时未同步迁移本地图片。
- 翻译改写简写图片／链接标签后可能破坏引用：现保护已定义的隐式引用，显式链接的显示文字仍可翻译。
- 中文输入法确认候选字时可能误触字体选择：组合输入期间不处理面板快捷键。
- 手动字色与高亮自动对比色叠加时可能出现编辑／导出不一致：显式字色优先。
- 格式变化时批注重复全文定位；文字编辑时每条批注重复计算相同前后缀。
- 搜索遍历空目录时不能及时响应取消。

## 资源与响应实测

2.2 万字符、100 条批注的定位微基准：格式变化计算由 1,066 ms 降至 1 ms，末尾编辑由 773 ms 降至 8 ms。这只衡量批注定位计算。

同一份 23,565 字节公式文档的源码版进程树测试：空闲 CPU 占整机 0.028%–0.112%，已缓存文档切换约 140 ms。浏览 8 份文档后保留 3 个渲染进程，关闭其中 7 份后回到 1 个。单份文档私有提交约 765 MiB，8 份全部浏览后约 1,731 MiB；WebEngine 的基础内存开销仍较高，不据此宣称内存相较历史版本下降。

未引入新运行库或字体包。局部格式保存为 Markdown 内嵌 HTML 样式，其他阅读器的显示取决于其 HTML/CSS 支持。安装体积和安装器验证留待后续打包阶段。

本地原始测量位于 `tmp/review-performance/latest.json` 和 `tmp/resource-benchmark/text-styles-current.json`，均未纳入仓库。测量方法与复现说明见 [资源实测与优化说明](resource-optimization.md)。
